# TypeFlow

Native offline-first Android touch-typing tutor built with Kotlin and Jetpack Compose.

## Requirements
- Android 10 (API 29) or newer
- English QWERTY physical keyboard recommended (USB OTG or Bluetooth)
- Fully offline; progress stays on-device

## Status
Project initialization. Implementation is being added in phases; this README will be updated as features become buildable and verified.
